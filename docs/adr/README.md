# Architecture Decision Records (ADR)

This folder holds formal Architecture Decision Records for this repository.

## What belongs here
A decision that constrains the standard's future direction, is costly to reverse, and needs a status tracked over time — scoped strictly to mars-standard's own technical governance.

## Naming
`ADR-NNN-<slug>.md`, sequential.

## Status lifecycle
`Proposed` → `Accepted` → `Deprecated` / `Superseded by ADR-NNN`

## Template
```
# ADR-NNN: <Title>

**Date:** YYYY-MM-DD
**Status:** Proposed | Accepted | Deprecated | Superseded by ADR-NNN

## Context
## Decision
## Rationale
## Consequences
- **Positive:**
- **Negative:**
```
