# MARS MCP Manifest (v0.2 Roadmap)

This directory is reserved for the `mars_mcp_manifest.yaml` file, which will define the standard Model Context Protocol (MCP) interface for AI agents to query MARS-compliant datasets.

**Why is it not here in v0.1?**
An MCP manifest is only useful when there is a live endpoint for agents to test against. We are deferring the manifest publication to v0.2, which will coincide with the release of the Aikya demo dataset and live endpoint.
